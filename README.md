# Hotel Board 🏨

Application de gestion de tableau de bord d'hôtel développée avec Flutter.

## Fonctionnalités
- Gestion des chambres (GL / LD) et de leur état (Libre, Occupée, Sale).
- Prise en compte du tarif spécifique pour client seul ou couple.
- Module de notes et observations par chambre.
- Suivi du journal des paiements et calcul du chiffre d'affaires quotidien.
